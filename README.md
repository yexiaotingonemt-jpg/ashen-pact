# 灰烬契约 · Borrow Tomorrow

**用未来的回合，支付眼前的力量。** 原创暗黑奇幻单人卡牌对战游戏。

**[立即游玩](https://yexiaotingonemt-jpg.github.io/ashen-pact/)** · [单文件版](https://yexiaotingonemt-jpg.github.io/ashen-pact/standalone.html)

## 2.3 · 看见我方随从的作用

- 随从发动能力时亮起并显示能力名，配合来源头像、效果连线和实际结果。
- 织者抽牌会高亮新牌，手机自动将其移入可见区域；治疗、加甲、加攻、汲取、启示等分别说明来源。
- 守卫与圣盾在受击时明确显示拦截和抵消数值；满血、手牌溢出、疲劳也说明真实结果。
- 我方召唤和攻击加入短动画，多名随从触发时依次展示。

实现与验收见[我方随从能力表现](design/ally-feedback-2026-10-24.md)。

## 2.2 · 看清敌方每次行动

- 敌方随从逐个攻击，每击约半秒：短促前冲、指向目标的箭头、受击高亮和独立伤害数字。
- 明确标出攻击的是“你（英雄）”还是“你的随从”；随从阵亡会先显示受击，再退场。
- 首领召唤及骑士倒戈有独立入场提示，新入场随从在之后的敌方回合按原规则攻击。
- 动画中刷新不会重复结算，旧存档继续可用。低动态效果设置下仍保留箭头和目标提示。

实现与验收记录见[敌方行动表现](design/enemy-playback-2026-10-24.md)。

## 2.1.1 · 催债提前预警

当下回合的催债会改变偿还日期时，战场摘要直接显示具体提前代价，例如“下回合提前兑现 12 生命”。账簿保留契约原日期；转嫁、焚毁、延期后提示即时更新。预警只依据当前公开条款，不预测随从阵亡等后续变化。无催债时仍显示普通账面到期摘要。

## 2.1 · 契约不会随死亡消失

- 借来的骑士阵亡后留下 3 点血债，保留原到期日；已有倒戈利息每层再加 2，可继续改写或转嫁。
- 没有己方债务时，催债造成 2 点可格挡伤害，罚息为首领增加 3 护甲。
- 战场直接显示最近账面到期的偿还汇总，点击可查看完整账簿；催债仍可能使日期提前。

旧存档继续可用。完整试玩、候选对照与验证局限见[本轮平衡报告](design/playtest-balance-2026-10-23.md)。

## 卡牌改变的是未来

- **预支**：0 费召唤 4/5 突袭骑士，但两回合后它会倒戈；立刻获得护甲，代价是下回合少抽牌。
- **看见**：双方未来三回合的契约写在同一本账簿中，每个敌方技能也是可以干预的承诺。
- **延期**：推迟债务或敌方承诺。己方债务会加息，同一契约最多延期两次。
- **改写**：把倒戈改成血债，保住骑士；把血债改付能量，调整承担的资源。
- **转嫁**：把可转移的代价交给首领，再用提前清算让它立即兑现。
- **清账**：提前击败首领也不能抹去债务。未兑现债务战后折付生命，付不清仍会失败。

可尝试的组合：**明日之焰 → 债务转嫁 → 提前清算**。先造成 6 伤害，再让首领立即支付 8 生命。

## 内容与操作

30 种卡牌、18 张起始牌组、7 件遗物、5 场首领战、3 档难度。保留守卫、圣盾、突袭、共鸣、复苏、汲取、灼烧，新增围绕操纵与兑现契约的随从。失明司祭会催债，黑誓统领会追加罚息，它们的承诺同样提前公开。

1. 点击随从牌，再点击空位召唤。点击就绪随从，再点击敌人攻击。
2. 点击法术牌，再选择目标；自用法术直接生效。
3. 点击改写牌，再点击账簿中亮起的契约；也可点契约详情，直接使用手中合适的牌。
4. 结束回合：敌方随从先攻击，随后推进时间、补满能量，按签署顺序兑现到期契约，最后治疗与抽牌。
5. 战后先清账，再领取卡牌、遗物和营火行动。营火可休息、升级或移除卡牌。

快捷键：**1–8** 选牌，**E** 英雄技能，**Esc** 取消，**空格** 结束回合。按钮获得焦点时，空格按浏览器标准行为激活该按钮。

手机可竖屏游玩，手牌左右滑动。浏览器自动存档；同一浏览器和地址使用同一存档。v2 使用独立存档键，保留之前版本数据。音效默认关闭。

## 契约规则

| 条款 | 到期时 |
| --- | --- |
| 血债 | 承担方直接失去生命，无视护甲 |
| 能量债 | 扣除已补满的能量；不足部分每点折付 3 生命 |
| 抽牌债 | 减少本回合的两张回合抽牌；不足部分每张折付 3 生命 |
| 倒戈 | 绑定随从加入敌方；敌方战场满时被收回，首领获得 4 护甲；阵亡改为原到期支付 3 生命，已有倒戈利息每层再加 2，仍可改写或转嫁 |
| 敌方承诺 | 执行公开的攻击、护甲、召唤、催债或加息，可延期或焚毁 |

改写汇率：**1 能量/抽牌 = 3 生命**；血债改付能量时向上取整。倒戈改写为 7 生命血债，每次延期利息再加 2。己方普通债务每次延期金额 +1，倒戈改为骑士攻击 +1。只能排入未来三回合。

击败首领后，未兑现己方债务按上述价值折付生命，随后才发放胜利回血。转给首领的债务不计入你的账单。账簿右上角可随时查阅完整规则。

## 本地开发

使用 Node.js 22 或支持 Vite 7 的版本。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm start
```

- 开发与成品服务器默认使用 `http://127.0.0.1:5183`，请勿同时占用。
- 构建生成 `dist/` 和根目录 `灰烬契约.html`。单文件已内嵌脚本、样式与美术。
- Windows 可运行 `开始游戏.cmd` 启动已构建的本地网页版。
- 单文件在不同文件位置或浏览器下可能使用独立存档，推荐使用在线地址。

## 结构与部署

- `src/engine.js`：确定性、可序列化的战斗和远征规则。
- `src/contracts.js`：时间线、可操作性、文案和清账价值。
- `src/Timeline.jsx`：可点击的三回合账簿。
- `src/App.jsx`：引导、契约详情、奖励、营火、交互与存档。
- `src/data.js`：卡牌、首领、遗物和难度。
- `public/art/`：本地正式美术，无第三方运行时图片依赖。
- `tests/`：规则测试及自动策略远征验证。
- `.github/workflows/pages.yml`：推送 main 后，先测试，再构建并部署 GitHub Pages。

美术由内置 Image Gen 生成，提示集见 [design/art-prompts.md](design/art-prompts.md)。界面文字、规则、图标、状态和交互均为原生代码。无需账号、服务端、支付或 API 密钥。
