# 四流派构筑与数值验证（2026-10-24）

本轮目标是让灼烧、护甲、治疗从通用辅助效果变成可以主动选择、稳定获得组件、具有不同获胜方式的构筑，同时保留“预支未来、操纵代价”的契约主轴。

本文区分规则事实、程序模拟与设计判断。**所有“通关/场数”均为一个受限自动策略的模拟结果，不是人类胜率，也不是最优策略胜率。** 结论不替代完整浏览器试玩。

## 1. 设计目的与共同预算

四条路线共用相同战斗规则与资源预算，以便差异来自组件如何组合，而非开局免费获得更多资源。

| 共同约束 | 本轮规则 | 数值职责 |
| --- | --- | --- |
| 卡池 | 39种牌，新增9种：每个新流派3种 | 给每条新路线补充资源来源、收益与转化手段 |
| 起始牌组 | 8张共享牌＋所选路线4张，共12张 | 缩小旧18张公共牌组的稀释作用 |
| 首战起手 | 保证所选路线核心随从在首战5张起手中，其余4张随机 | 保证有机会使用核心，不保证能立即触发其能力 |
| 战后选牌 | 前4战各两轮3选1，整局最多加入8张；每轮可放弃并恢复4生命 | 增加构筑改造空间；两轮放弃总计仍为8生命 |
| 第一轮奖励 | 2个本路线池候选＋1个混合非本路线池候选 | 提供稳定补件与转向选择 |
| 第二轮奖励 | 1个本路线池候选＋1个其他路线池候选＋1个混合非本路线池候选 | 保留跨流派组合；第三槽不承诺是“纯通用牌” |
| 重复候选 | 同一战优先展示未出现的卡，同一轮不重复 | 降低两轮选牌看见相同选项的情况 |
| 战场 | 每侧最多3个随从 | 多核心叠加需要让出守卫、输出或治疗的位置 |
| 能量 | 通常3点起始，每回合上限＋1，最高8；熔心石另加起始上限 | 资源牌与收益牌需要共享出牌预算 |
| 手牌与循环 | 上限8；弃牌会洗回；消耗牌本战不洗回；空牌库进入疲劳 | 控制连打和过牌，保留抽牌溢出的取舍 |
| 时间压力 | 余火/契约/永夜分别从第10/7/6回合开始狂怒 | 防止防御路线只囤资源、不推进胜利 |

共享8张为：灰烬侍卫、余烬飞弹、铁壁誓约、温存余火、禁书启示、破晓枪骑、明日之焰、再借一天。各路线再加入4张明确的组件。

| 路线 | 起始专属4张 | 资源到胜利的连接 |
| --- | --- | --- |
| 命运书契 | 借来的骑士、债务转嫁、因果织者、提前清算 | 预支获得节奏，操纵带动书契过牌，把血债转嫁并提前清算 |
| 焚心余焰 | 焚心印记、余焰司灯人、续火、焚账引爆 | 叠加灼烧，选择保留持续伤害或消耗层数换取即时伤害 |
| 铸甲反击 | 日蚀壁垒、誓炉铸甲师、碎甲反击、淬甲仪式 | 守卫保护英雄，获得护甲带动锻甲成长，花掉护甲完成反击 |
| 薪火复苏 | 薪火祭司、返照医者、烛火裁决、余温成盾 | 治疗触发返照伤害，溢出治疗可通过余温成盾变成护甲 |

以上是构筑方向，不是排他职业。牌可以跨路线获得，例如余温成盾也能触发锻甲。

## 2. 放大关系与循环限制

- **灼烧不是线性库存。** 在目标一直存活、没有护甲/圣盾、没有追加或引爆的条件下，N层灼烧依次造成N、N−1……1伤害，总和为N(N＋1)/2。3层为6，6层为21。因此引燃限定为每名司灯人每回合第一次施加灼烧额外＋1层；没有每次追加都递归触发的规则。引爆先清除全部层数，再造成3＋层数×2伤害；被圣盾抵消也不退回层数。
- **护甲转伤害要真实付款。** 碎甲反击消耗至多9护甲，造成2＋消耗量伤害；升级后为至多12护甲与3点基础伤害。再次使用只能花剩余护甲，不能无损重复读取已累积的护甲。锻甲每名铸甲师每回合只成长一次，＋2攻击。
- **治疗含溢出是明确规则。** 返照每名医者每回合只响应前两次正数英雄治疗事件，每次造成2伤害；满血治疗也可触发，以免健康开局使整套路线失效。多个医者各自计数，但共同占用3个随从位。返照只造成伤害，不回调治疗，因此没有治疗→返照→治疗的递归。
- **转化口径分开。** 余温成盾只把未恢复到生命上的部分变成护甲；给随从的共生契约不属于治疗英雄。营地、选牌放弃和战后恢复不触发返照。
- **计数随存档保存。** 引燃、锻甲与返照使用随从上的回合标记/次数；刷新页面不会重新获得同回合触发预算。旧存档允许缺少新字段，保留已有牌组；新开远征才使用12张起始牌组。

这些规则约束新增正反馈。模拟器另设每回合32次行动、每局1200次行动的故障保护；它不是游戏规则，也不用于证明数值平衡。最终160局以及32局消融均未触发每回合保护，所有远征都正常结束。

## 3. 模拟命题、方法与信息边界

要检验的是：四路线能否完成远征、核心是否实际触发、定向奖励是否能够形成构筑，以及是否出现同时最快且最稳的明显异常路线。

复现入口：`scripts/archetype-sim.mjs`。

```sh
node scripts/archetype-sim.mjs --normal=24 --other=8 --out=archetype-final.json
node scripts/archetype-sim.mjs --normal=8 --only=normal --ablation=core --out=archetype-core-ablation-final.json
```

- 完整规则共160局：标准“契约”难度每路线24局，余火与永夜每路线各8局；对应种子均为571×1、571×2……，路线间复用相同种子编号。
- 使用同一套有限两步搜索算法，每步重新决策；保留6个首步候选继续评估第二步，因此能识别部分“先准备资源，再使用收益牌”的组合。路线的选牌偏好与护甲估值有所区别，并非四路线使用完全相同的卡牌优先级。
- 策略可读当前手牌、双方公开实体、公开三回合账簿、公开牌组/弃牌/消耗牌组成及牌库张数。**真实牌库内容与顺序、真实随机种子不输入规划器。** 规划时以不透明占位牌替代抽牌堆、以常量替代种子；新抽到的牌不能用于当前两步搜索，实际抽牌后才重新决策。
- 入口带有信息边界断言：真实种子的getter与抽牌堆除`length`以外的访问都会抛错；改变真实种子和隐藏牌序不改变相同公开局面的决策。
- 奖励优先考虑路线协同，同时降低过多同类随从的价值；营地生命低于24时休息，否则升级。策略没有完整的跨回合留牌规划，没有人类操作误差，也没有使用隐藏信息挑选奖励。
- 每次真实行动验证存档结构；以最终结算后的`s.turn`记录每段已结束战斗的回合数。表中生命是整局结束生命，**不是战斗期间最低生命**。触发次数来自真实`actionFeedback`及敌方帧/尾部反馈，不按出牌名称猜测。
- 最终JSON记录数据、引擎、模拟脚本的SHA-256，便于区分规则版本。本文采用终局边界修复后的最终矩阵，不把先导结果冒充最终结果。

## 5. 小样本核心被动消融

取标准难度各路线前8个相同种子，分别只在模拟进程内移除书契、引燃、锻甲或返照标签。保留牌数、费用、随从身材、主动牌效果和奖励池，不修改源数据。策略不再给被关闭的被动额外估值。

这是一项单被动消融，**不是删除三张新牌**。它避免给牌组塞入三张完全无作用的牌，但也不能证明所有新牌均为通关必要条件。

| 路线 | 完整/关闭被动的通关数 | 完整/关闭被动的每战平均回合 | 完整/关闭被动的最终生命 |
| --- | ---: | ---: | ---: |
| 命运书契 | 8/8 → 7/8 | 5.25 → 5.50 | 31.63 → 24.38 |
| 焚心余焰 | 8/8 → 8/8 | 4.50 → 4.78 | 31.75 → 34.75 |
| 铸甲反击 | 8/8 → 8/8 | 5.10 → 5.48 | 34.75 → 33.38 |
| 薪火复苏 | 8/8 → 8/8 | 5.10 → 6.15 | 38.38 → 38.50 |

关闭返照后仍能保命，但平均每战延长约1.05回合，符合“把治疗转成推进胜利的伤害”的设计职责。引燃与锻甲的关闭也令本样本战斗变慢。书契少一次通关，提示抽牌连贯性的重要性。灼烧关闭引燃后生命反而提高，说明策略会改变行动与后续奖励路径，不能把这组小样本当作单纯伤害系数实验。契约消融包含一次最终战失败，不能只用平均回合的变化判断收益大小。

## 6. 规则审计与真实修复

审计覆盖新升级、资源消费、回合边界、输入不变、最终状态与播放元数据一致、旧存档与两轮奖励进度。记录时测试为128项通过。

- 提前清算原先升级只尝试降低已经为0的费用；现升级明确把额外血债伤害由＋2改为＋5，仍0费、仍消耗、仍无视护甲。
- 新法术的多效果升级使用显式字段，烛火裁决同时由3伤/3治疗升为5伤/5治疗；续火、淬甲仪式、余温成盾保留各自抽1张效果；三个新随从升级身材，不提升每回合触发次数。
- 盾击与引爆先消费资源，被圣盾抵消不会返还。零护甲/零灼烧仍只产生各自基础伤害。死亡目标不继续获得灼烧，也不消耗引燃次数。
- 同一新回合内，契约见证所得护甲与指环护甲共用一次锻甲预算；祭司治疗使用新回合的返照预算。序列化/重载不重置这些预算。
- 两轮奖励中的非法选择不消耗进度；第二轮存档重载后不能重复领取第三张。每轮放弃恢复4，总计8。
- **实际发现并修复了回合开始的终局问题：** 祭司治疗触发返照击杀首领后，旧处理还会继续抽牌、疲劳、安排新承诺；英雄1生命、首领2生命、无牌可抽的边界局面会被后续1＋2疲劳改判失败。现每名祭司完成治疗/返照后立即检查终局并停止后续步骤；仍先结算未付债务，付不起账仍会失败。相关致死与未付血债用例已覆盖。
- 复苏/汲取的反馈先显示来源治疗，再显示返照后续伤害，修正原先反馈数组的因果顺序。显示元数据留在状态之外。

完整160局与32局消融均在上述终局修复后重新运行，未沿用先导版本的数据。

## 8. 设计判断与局限

**当前判断：保留本轮数值，优先验证真人决策体验。** 本样本没有出现同时最快、最稳且最低投入的路线，不因自动策略全通关直接提高所有难度。

- 灼烧在标准难度平均4.47回合结束一战，比其他路线更快，但平均最终生命29.88；其中一局只剩8生命。永夜同样最快、平均生命也最低。等待持续伤害与消耗层数引爆形成了实质节奏取舍。
- 护甲每次盾击平均实际消费约7.19护甲；它没有免费反复复制整份护甲。完整样本中护甲路线最高观察到44护甲、13随从攻击；增长仍占用回合、出牌和站位预算。
- 治疗保持最高生存余量，但没有获得灼烧的战斗速度。永夜8局中7局最终满血，是后续真人高难试玩应继续关注的强度信号，不能因为次数上限存在就宣称它已经完全平衡。
- 灼烧样本最高17层，证明层数放大必须持续监测；层数理论总伤害不等于实战已造成伤害，目标可能提前死亡、被引爆或受到护甲影响。
