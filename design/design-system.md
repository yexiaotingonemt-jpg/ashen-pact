# 灰烬契约 · 视觉与实现约定

主参考：battle-concept.png，1536 × 1024。完整牌桌包括品牌、五节点远征、左侧英雄与能量、敌方首领与意图、三对三随从位、右侧回合旗帜、下方手牌和牌堆。

- 色彩：墨绿 #101917、炭黑 #0b100f、旧金 #b49660、浅金 #ead4a0、象牙 #f2e8d3、余烬 #db6645、灵火 #6ed3c2。
- 字体：中文标题宋体，界面正文微软雅黑，数字 Georgia；本地系统字库，无在线字体依赖。
- 金属边框、菱形费印、卷边标题、生命红宝石、青色能量球为共用组件。
- 生成素材：courtyard.png 为独立无字背景；portraits.png 为十二格绘画图集，四列三行。UI 和文字保持 DOM 原生。
- 动效：出牌升起、攻击脉冲、伤害浮字、回合提示、少量余烬粒子；支持减少动态效果。

卡牌为文字密集的 DOM 交互，采用 React + Vite 和 CSS，规则为独立可序列化纯 JS 模块；无需物理、移动角色或游戏引擎。与默认 Phaser 路线的偏离用于保证卡面文字、键盘和触屏可访问性。

功能需要的有意调整：卡面显示简短关键词与明确数值；首战敌人数值适合新手；右侧增加 2 费英雄技能与意图解释；奖励、营火、卡组和规则是同主题弹层。移动端改为可横向滑动的手牌和紧凑英雄条。

v2「未来契约」在原美术体系内加入三回合命运账簿，替换原 VS 分隔区。预支卡使用金色费用、红色未来代价，改写卡使用青色类别；敌方承诺、己方债务和已转嫁血债采用不同颜色。为保留可读空间，小尺寸桌面缩小随从肖像，手机手牌保持原尺寸并横向滚动。新增初次引导、契约详情、快捷改写和清账规则弹层。新版本共有 30 种卡牌，起始牌组 18 张，与 v1 参考图的示例数值有意不同。
